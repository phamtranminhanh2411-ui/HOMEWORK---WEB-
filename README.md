# HOMEWORK WEB

## Chạy dự án

Cần Node.js/npm và MongoDB đang chạy tại `mongodb://127.0.0.1:27017`.
Dữ liệu Fashion sử dụng database `FashionData`, collection `Fashion`.

Terminal thứ nhất:

```powershell
cd my-server-mongodb
npm install
npm start
```

Terminal thứ hai:

```powershell
cd my-app
npm install
npm start
```

Mở `http://localhost:4200`. Có thể thêm dữ liệu từ menu **Fashion New**.
Nếu dùng các bài Book, chạy thêm `npm install` và `npm start` trong `my-server`.

Nhánh `homework/fashion-slug` có commit nền và commit riêng cho bài IdF/Slug Fashion.
